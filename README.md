# Sowgoto Raha Sunny — Professional Portfolio

This repository contains the production-ready static portfolio for [sowgoto.github.io](https://sowgoto.github.io/).

The site presents:

- Professional experience in systems engineering, DevOps support, cloud operations, and production reliability
- Technical projects across incident triage, cryptography, ransomware defense, network security, e-commerce security, and data analysis
- Research interests and selected publications in cybersecurity, explainable AI, federated learning, and resilient systems
- Education, certification, skills, résumé, and contact links

## Pages

- `index.html` — homepage
- `experience/` — experience, technical skills, education, and certification
- `projects/` — selected technical projects with GitHub links
- `research/` — research interests and publications
- `contact/` — email and professional profile links

## Deployment

This is a dependency-free static site built for GitHub Pages. Upload all files and folders to the root of the `Sowgoto/sowgoto.github.io` repository, then enable GitHub Pages from the repository's default branch and root folder.

See `UPLOAD-INSTRUCTIONS.txt` for step-by-step instructions.

## Local preview

From the repository root:

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.
