# Sowgoto Raha Sunny — Academic & Engineering Portfolio

This repository contains the production-ready static portfolio for [sowgoto.github.io](https://sowgoto.github.io/).

The site presents:

- Cybersecurity and AI research in explainable intrusion detection, DDoS detection, distributed learning, and resilient systems
- Publications and manuscripts listed according to the academic CV
- Teaching experience in applied machine learning
- Professional systems engineering, cloud operations, automation, incident response, and production reliability experience
- Selected research and technical projects, education, certification, skills, CV, and contact links

## Pages

- `index.html` — homepage
- `research/` — research experience, methods, results, and interests
- `publications/` — publications and manuscripts
- `experience/` — research, teaching, engineering, skills, education, and certification
- `projects/` — selected research and technical projects
- `contact/` — email and professional profile links

## Deployment

This is a dependency-free static site built for GitHub Pages. Upload all files and folders to the root of the `Sowgoto/sowgoto.github.io` repository, then enable GitHub Pages from the repository's default branch and root folder.

See `UPLOAD-INSTRUCTIONS.txt` for step-by-step instructions.

## Local preview

From the repository root:

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.
