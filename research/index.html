2025–Present · Independent research

Explainable deep learning for network intrusion detection

I developed NML-XAI, an explainable intrusion-detection framework combining Transformer-based feature processing, CNN–BiLSTM–attention–autoencoder models, and ensemble stacking. The study uses SMOTE for class imbalance and SHAP and LIME for interpretable security analysis on UNSW-NB15.

2025–2026 · Collaborative research

Hybrid KAN and explainable AI for DDoS detection

This work designs a hybrid Kolmogorov-Arnold Network and explainable AI pipeline for multi-class DDoS detection in software-defined networks. I contributed to experimental design, model evaluation, technical analysis, manuscript preparation, and research documentation.

Model design

Hybrid Kolmogorov-Arnold Network

Combines learned representations and explainability to support more reliable security decisions.

Application

Multi-class DDoS detection in SDN

Targets network attacks in programmable, software-defined infrastructure.
